# SHARQ — نظام إدارة اللوحات الكهربائية

تطبيق Streamlit خفيف لإدارة اللوحات الكهربائية: رفع مخطط PDF وقائمة أصناف Excel لكل لوحة،
حفظها داخل نفس مستودع GitHub، توليد رابط + QR Code، وعرض صفحة عميل تفاعلية بها مساعد
بحث فني محلي مجاني بالكامل (بدون أي ذكاء اصطناعي خارجي وبدون Google Cloud Console).

## هيكل المشروع
```
sharq_app/
  app.py                  # نقطة الدخول (لوحة التحكم + صفحة العميل)
  requirements.txt
  modules/
    storage_utils.py       # التخزين داخل نفس مستودع GitHub (بدون Google)
    excel_utils.py          # قراءة والتحقق من ملف الإكسل
    pdf_utils.py             # استخراج نص PDF لتغذية المساعد الفني
    qr_utils.py               # توليد QR Code
    ai_assistant.py            # المساعد المجاني (بحث محلي فقط)
  .streamlit/
    secrets.toml.example    # نموذج ملف الأسرار
```

## خطوات التشغيل (محلياً)
1. `pip install -r requirements.txt`
2. انسخ `.streamlit/secrets.toml.example` إلى `.streamlit/secrets.toml` واملأ القيم الحقيقية.
3. `streamlit run app.py`

## متطلبات الإعداد قبل أول استخدام

### 1) التخزين — داخل GitHub نفسه، بدون Google Cloud Console إطلاقًا
لا حاجة لأي حساب Google Cloud أو تفعيل تحقق بخطوتين؛ الملفات تُحفظ كملفات عادية
داخل نفس مستودع الكود على GitHub، عبر رمز وصول شخصي (Personal Access Token):
1. اذهب إلى `github.com/settings/tokens` (من إعدادات حسابك في GitHub مباشرة).
2. اضغط `Generate new token` → `Generate new token (classic)`.
3. اختر صلاحية `repo` فقط، ثم `Generate token`.
4. انسخ الرمز (يبدأ بـ `ghp_`) وضعه في `github_token` داخل `secrets.toml`.
5. ضع اسم مستودعك بصيغة `اسم_المستخدم/اسم_المستودع` في `github_repo`.

### 2) المساعد الفني — مجاني بالكامل، بدون أي مفتاح
المساعد لا يستدعي أي خدمة ذكاء اصطناعي خارجية إطلاقًا. هو محرك بحث محلي
(`modules/ai_assistant.py`) يطابق سؤال الفني مباشرة مع صفوف ملف الإكسل ونص PDF
المرفقين لهذه اللوحة فقط، فلا توجد أي تكلفة تشغيل مستمرة ولا حدود استخدام يومية.

### 3) النشر على Streamlit Cloud
- ارفع هذا المجلد إلى مستودع GitHub (نفس المستودع المذكور في `github_repo`).
- أنشئ تطبيقًا جديدًا على Streamlit Cloud يشير إلى `app.py`.
- الصق نفس محتوى `secrets.toml` داخل إعدادات "Secrets" في لوحة تحكم التطبيق.
- ضع رابط التطبيق النهائي في `app_base_url` داخل الأسرار (يُستخدم لبناء روابط QR).

## طريقة الاستخدام
1. افتح رابط التطبيق مباشرة (بدون `?panel=`) → تفتح لوحة تحكم SHARQ الداخلية، تسجّل
   الدخول بكلمة المرور (`admin_password`).
2. من تبويب "New Panel": ارفع ملف الإكسل (Part Number, Description, Quantity) وملف PDF
   للمخطط، وحدد تاريخ التركيب ومدة الضمان → يولّد التطبيق معرّف لوحة فريد + رابط + QR
   جاهز للطباعة ولصقه خلف باب اللوحة (الملفات تُحفظ تلقائيًا كـ commits داخل مستودع GitHub
   نفسه، في مجلد `data/<معرف اللوحة>/`).
3. عند مسح الفني للـ QR، تفتح صفحة العميل مباشرة (الرابط يحمل `?panel=<ID>`) وتعرض:
   حالة الضمان، زر تحميل المخطط، زر واتساب للدعم الفني، وصندوق أسئلة يجيب حصريًا من
   بيانات هذه اللوحة.

## ملاحظات مهمة
- لا توجد أي أسعار أو قيم مالية في النظام؛ ملف الإكسل يقتصر على ثلاثة أعمدة فقط.
- المساعد لا يخمّن أبدًا ولا يستخدم أي ذكاء اصطناعي حقيقي: هو بحث مباشر داخل بيانات
  اللوحة فقط، وأي سؤال لا يطابق شيئًا في الملفات يحصل على رسالة الرفض الثابتة
  الموجّهة للقسم الفني. هذا يجعل النظام مجانيًا بالكامل وبدون أي احتمال هلوسة إطلاقًا.
- التخزين داخل GitHub مناسب لملفات الإكسل والـ PDF العادية (حتى عشرات الميجابايت لكل
  ملف)؛ لو أصبح حجم المخططات كبيرًا جدًا مستقبلًا (عشرات آلاف اللوحات)، يُفضّل الانتقال
  لاحقًا إلى تخزين سحابي مخصص.
- التصميم مبني على هوية "الشرق" (خلفيات شفافة، حدود نيون أخضر لامعة، أزرار كروم متدرجة)
  المأخوذة من واجهة SORTPRO المرجعية.
